# Задание 1. Проектирование технологической архитектуры

## 🎯 Основные решения архитектуры

### 1. **Мультирегиональное развертывание**
- **Два региона** (Центральная Россия и Урал) для покрытия разных часовых поясов
- **Global Load Balancer** с GeoDNS для маршрутизации по близости
- **Active-Active** конфигурация сервисов

### 2. **Стратегия масштабирования**
- **Горизонтальное масштабирование** Kubernetes кластеров
- **Read replicas** для баз данных

### 3. **Отказоустойчивость**
- **RTO 15 мин, RPO 5 мин** (лучше требований бизнеса)
- **Синхронная репликация** PostgreSQL между регионами
- **Health-based routing** через Global Load Balancer

### 4. **Производительность**
- **Redis Cluster** для кэширования сессий
- **CDN** для статических ресурсов
- **Connection pooling** и query optimization

### 5. **Безопасность и контроль**
- **WAF** (Web Application Firewall) - защита от OWASP Top 10
- **Rate limiting** на уровне Load Balancer
- **Мониторинг** Prometheus + Grafana + Alerting
- **Audit logging** и трассировка запросов

### 6. **База данных**
- **PostgreSQL кластер** с мастером и синхронными репликами
- **Регулярные бэкапы**
